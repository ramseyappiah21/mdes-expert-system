## Checkpoint answer (brief)

Roles are technical, not ceremonial. The two knowledge engineers own *what is true* in the domain. The rule designer owns *how experts decide*. The two programmers encode those decisions so they can be queried. Testing, documentation, presentation, and QA close the loop so the live demonstration matches the written report.
